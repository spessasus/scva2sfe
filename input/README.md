# input

Put `SCCore.dll` from SOUND Canvas VA 1.1.6 (x64) here (or pass its path anywhere), then run
`node bin/scva2sfe.mjs input/SCCore.dll`. Optional: `SCVSC.drk` and `GM2.drk` from the same install next to it, for the
drum key names (without them the keys are named after their tones).
Nothing in this folder is part of the repository.
